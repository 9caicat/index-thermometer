成本锚 / COST ANCHOR

成本锚是什么？图表就三条线：200 日定投成本线、850 日长期成本线、月度210均线，代表中短期成本、长期成本和超长期成本的参考位置。（周线模式为 50 周 / 200 周）。黄线在红线上方，说明市场的短期持仓者整体浮盈；价格跌入红线下，说明连定投的人都被套；跌破蓝线，说明当前价格已经低于过去 3-4 年的持有均价，若价格跌破绿线，则意味市场可能将进入长期低估值区间。注意：所有指标仅供学习交流使用，不构成任何投资建议和依据！

宏观背景。200 日（约一年）覆盖一轮货币与库存周期；850 日（约 3.5 年）跨越一轮完整的信贷周期；50 周与 200 周是同一逻辑的周线版，采样更稀、曲线更平滑，适合判定大级别牛熊。成本线的斜率由宏观周期决定：持续上翘对应扩张期，走平下弯对应收缩期。

微观结构。价格与成本线的关系，就是市场平均持仓者的浮盈浮亏状态——价格在成本线上方时，整体浮盈、情绪偏热，偏离过大易回踩；在下方时，整体浮亏、割肉动力衰竭、情绪偏冷，价格线随之由黄转蓝。850 日线与 200 周线是牛熊分水岭：线上运行趋势向上，有效跌破趋势走坏，回踩不破即是支撑。价格高于短期成本、短期成本高于长期成本，构成多头排列，反之为空头排列。

850黄金乘数 / GOLDEN MULTIPLIER

850 黄金乘数是什么？以 850 日均线为价值中枢，向上将价格相对长期均价的上行偏离，转化为直观的倍数刻度，得到 1.6 倍、2 倍、3 倍、5 倍四条乘数带。价格越靠近上方的乘数带，说明相对长期均值偏离越大，切不可简单理解为交易信号。注意：所有指标仅供学习交流使用，不构成任何投资建议和依据！

宏观背景。850 日（约 3.5 年）跨越一轮完整的信贷与产能周期，其均线可视作指数的长期价值中枢；价格相对中枢的倍数偏离由流动性与风险偏好驱动，具有显著的均值回归特征。乘数 1.6 / 2 / 3 / 5 取自黄金分割与历史极值统计：1.6 近似黄金比例 φ，2 与 3 对应历史上阶段性顶部常见的偏离区间，5 则标记极端泡沫。

使用方法。价格运行于均线下方为低估区；均线至 1.6 倍为合理区；1.6 至 2 倍偏热、2 至 3 倍高热，应逐步降低追涨意愿；触及 3 倍以上进入泡沫区，历史上多对应大级别顶部区域，宜分批兑现而非加仓；跌回均线附近则是长期资金的分批布局区。乘数带随均线每日平移，斜率向上时顶部阈值同步抬升，斜率走平下弯时警惕带内假突破。

沪深300超跌基准 / OVERSOLD BENCHMARK

沪深300超跌基准是什么？把沪深300全收益指数与二级债基等效基准线放到同一起点（2004 年末 = 0%）对比累计涨幅：二级债基代表稳健资产的长期复利轨迹，当沪深300全收益的累计轨迹跌破这条基准线时，历史上多对应市场的底部区域，图中红点标记每次跌破的起点。注意：所有指标仅供学习交流使用，不构成任何投资建议和依据！

宏观背景。二级债基以债券资产为盾、少量权益为矛，长期呈低波动复利轨迹；沪深300全收益指数计入分红再投资，是权益资产的完整回报。两条曲线同起点（2004 年末 = 0%）对比累计涨幅，相当于观察权益与「固收+」自起点以来的累计复利赛跑。

观察方法。沪深300全收益运行在基准线上方，说明权益累计回报跑赢稳健固收；跌破基准线，则意味着权益长期复利已被反超——2005 年以来每次跌破都出现在大级别底部区域（2005-2006、2008、2011-2014、2018、2024 等），红点为历次跌破的起点标记，仅作历史事实展示。

口径说明。等效基准线以万得混合债券型二级指数（885007）的历史轨迹为准（本指标采用中证债券型基金指数（H11023）× 1.64 校准，近似 885007），请关注相对位置而非精确数值。跌破事件按「间隔 ≤15 个交易日的相邻区段合并」计为一次。
